# 时程簿

移动端优先、可安装到手机主屏的 PWA 个人全天时程管理应用。打开就能看到今天 24 小时的每一刻：上课、睡眠、自定义安排、计划，以及自动算出的空闲时间。

## 功能

- **课表**：每周 / 单周 / 双周 / 指定周，自动按学期开始日期计算单双周
- **睡眠作息**：就寝 / 起床时间（跨天显示）
- **安排 / 待办 / 计划**：一次性、每天重复、每周重复
- **计划推荐**：自动结合课表和睡眠寻找空闲时段，勾选确认后落地为日程
- **空闲自动计算**：24 小时减去课、睡、安排、计划，剩余即空闲
- **视图**：今天（24h 时间轴 + 现在卡）、周（7 天网格）、月（日历 + 色点）
- **主题色自定义**、**深色跟随系统**
- **数据本地存储**（IndexedDB），支持导出 / 导入备份
- **PWA**：可添加到主屏、离线可用

## 技术栈

Vite · React · TypeScript · Dexie(IndexedDB) · lucide-react · vite-plugin-pwa

## 本地运行

```bash
npm install --ignore-scripts --cache .npm-cache
npm run dev          # 开发服务器
npm run typecheck    # 类型检查
npm run build        # 生产构建（产物在 dist/）
npm run preview      # 预览生产包
```

## 目录结构

```
src/
  styles/      设计变量(tokens.css)与全局样式(app.css)
  lib/         日期/周次/日程计算、数据库、主题、状态管理
  components/  基础 UI 组件与时间轴/现在卡
  views/       今天/周/月/设置 四个视图
  editor/      添加/编辑抽屉（安排·课程·睡眠·计划）
```

## 使用流程

1. 「设置」→ 设定学期名称、开始日期（填第一周的周一）、结束日期
2. 首页点「+」→「课程」添加课表；「睡眠」设作息
3. 「+」→「安排」添加临时安排；「计划」创建计划并确认推荐时段
4. 底部导航切换 今天 / 周 / 月
