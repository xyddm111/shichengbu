# 时程簿 · Shichengbu 🕐

一个**移动端优先的 PWA 个人全天时程管理应用**。把「课表、睡眠、自定义安排、计划」统一到 24 小时时间轴，**空闲时间自动计算**，打开即见「今天每一刻」在干嘛。

> 🌐 **在线体验**（手机浏览器打开，可「添加到主屏幕」当 App 用）：
> **https://shichengbu-d7gzg85do31c9f03b-1481936482.tcloudbaseapp.com**

---

## ✨ 功能

- 📅 **课表**：每周 / 单周 / 双周 / 指定周 / 指定日期、一周多时段，自动按学期算周次
- 🌙 **睡眠作息**：跨天显示（就寝→次日 24:00 与 0:00→起床）
- 🗓 **安排 / 待办 / 纪念日 / 计划**：全天、每天/每周/每月重复、每周多选星期几、重要程度、提醒
- 🎯 **计划推荐**：自动结合课表和睡眠找出空闲时段，勾选确认落地
- ⏳ **空闲自动计算**：24 小时减去课/睡/安排/计划，剩余即空闲
- 📊 **三视图**：今天（24h 时间轴 + 现在卡）、周（7 天网格）、月（日历 + 色点）
- 📈 **统计**：时间分布、空闲占比、概览
- 🔔 **待办倒计时**：距离考试/截止日还有几天
- 🎨 **主题色自定义 + 深色跟随系统**（设计走极简工具感，无渐变，SVG 图标）
- 🌦 **天气**：当前温度 + 天气图标（定位或手动城市）
- 💾 **本地 + 云端双模式数据**：未登录存本地（IndexedDB），登录后自动上云、按账号隔离
- 📦 **PWA**：可安装到主屏、离线可用、数据导出/导入

## 🧠 核心设计

**「24 小时 = 课程 + 睡眠 + 安排 + 计划 + 空闲」**，空闲是自动算出来的剩余，不用手动维护。

数据层做了**本地/云端双模式**（接口一致，一行切换）：

```ts
// useAppData()（本地 IndexedDB）  ⇄  useCloudData()（CloudBase）
const store = authUser ? cloudStore : localStore
```

这样未登录也能用（无需账号），登录后数据上云、跨设备同步、按账号 `uid` 隔离。

## 📊 项目结构

```
src/
  styles/     设计变量(tokens.css) + 全局样式(app.css)
  lib/        日期/周次/日程计算、主题、本地&云端数据、天气
  components/ 基础组件 + 时间轴/现在卡/底部导航
  views/      今天/周/月/统计/计划/我的/登录
  editor/     全屏添加/编辑页
```

## 🔐 登录与多用户

- 采用「用户名 + 密码」登录，账号由管理员在 CloudBase 控制台「用户管理」创建。
- 登录后数据存云端、按账号隔离；未登录走本地模式。
- 👉 自助注册暂未开放（免费体验版限制，优化方向见 `docs/03-注册优化方向.html`）。
